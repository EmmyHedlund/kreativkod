EMMY HEDLUND — PORTFOLIO + FOREST FAIRY RAVE

Open index.html for the personal homepage. Click the Forest Fairy Rave card to open project.html.

The project page contains five photo slots and a video slot. Add your own media to assets/:
  bild1.jpg, bild2.jpg, bild3.jpg, bild4.jpg, bild5.jpg
  projektvideo.mp4
The gallery automatically loads photos if those filenames exist.

The interactive artwork is kept separately and unchanged in interactive-project/index.html.
It uses the webcam, p5.js, MediaPipe and Tone.js. Use HTTPS or localhost for camera access; click/tap to enable audio. Internet access is needed to load the external libraries.

Remember to upload/publish the site and check the video, all five photos, and the interactive artwork before submitting.
